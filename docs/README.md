## 版本与维护约定

- 文件名包含文档类型、版本和发布日期，便于区分草稿与现行基线；更新正式契约时保留版本历史，不静默覆盖旧版本。
- 需求、数据库和接口文档若出现冲突，先记录并确认，不以原型截图或技术建议覆盖正式契约。
- 图片按端与用途归档，原型截图按页面流程编号；候选背景保留候选标记，避免误认为已上线素材。
- `../AGENTS.md` 是仓库级开发规范；部署启动说明见仓库根目录 `../README.md`。
