# 微信手机号登录接口扩展

本扩展更新 V3.1 的 `A01 POST /api/app/auth/login`。

## 请求

```json
{
  "login_code": "wx.login 返回的一次性凭证",
  "phone_code": "getPhoneNumber 返回的一次性凭证"
}
```

不得接受客户端提供的手机号或 OpenID 作为认证依据。

## 成功响应

沿用 V3.1 `AppLoginVO`：`token`、`expires_in`、`member`（`id`、`phone`、`nickname`、`avatar`、`points`、`growth_points`）。会员 JWT 有效期仍为 30 天。

## 处理与错误

- 微信服务端兑换 `login_code` 得到本小程序 OpenID；使用服务端 access token 兑换 `phone_code` 得到手机号。
- 微信验证成功后按手机号复用或创建会员，并安全绑定 OpenID。已有会员身份与订单、积分关系保持不变。
- 绑定冲突返回 HTTP 409，提示联系管理员；无效授权凭证或微信服务异常不得签发令牌。
- 旧 `{phone}` 请求不兼容，缺少必填凭证返回 HTTP 400。
- 不新增接口、数据库字段或迁移。`members.openid` 可空且唯一，管理员预建账号可继续为空。

## 支付接口

住宿和商城支付现有接口保持原契约；其身份校验复用微信凭证服务，并继续将付款 OpenID 与已登录会员绑定身份进行核对。
