# 微信手机号登录接口扩展

本扩展更新 V3.1 的认证模块：保留 `A01 POST /api/app/auth/login` 微信授权方式，并新增 `A05 POST /api/app/auth/phone-login` 仅手机号方式。

## 请求

```json
{
  "login_code": "wx.login 返回的一次性凭证",
  "phone_code": "getPhoneNumber 返回的一次性凭证"
}
```

该接口不得接受客户端提供的手机号或 OpenID 作为微信身份认证依据。

## A05 仅输入手机号登录

**请求**：

```json
{"phone":"13800000000"}
```

仅校验中国大陆手机号格式，不验证号码归属、不调用微信。按手机号创建或复用会员，沿用 `AppLoginVO` 成功响应并签发 30 天 JWT。手机号若属于其他顾客，输入者可取得该会员身份及其受保护数据访问权。

## 成功响应

沿用 V3.1 `AppLoginVO`：`token`、`expires_in`、`member`（`id`、`phone`、`nickname`、`avatar`、`points`、`growth_points`）。会员 JWT 有效期仍为 30 天。

## 处理与错误

- 微信服务端兑换 `login_code` 得到本小程序 OpenID；使用服务端 access token 兑换 `phone_code` 得到手机号。
- 微信验证成功后按手机号复用或创建会员，并安全绑定 OpenID。已有会员身份与订单、积分关系保持不变。
- 绑定冲突返回 HTTP 409，提示联系管理员；无效授权凭证或微信服务异常不得签发令牌。
- 微信授权接口继续要求 `login_code` 和 `phone_code`；仅手机号登录使用独立 A05，不改变 A01 请求契约。
- 不新增数据库字段或迁移。`members.openid` 可空且唯一，管理员预建账号可继续为空。

## 支付接口

住宿和商城支付现有接口保持原契约；其身份校验复用微信凭证服务，并继续将付款 OpenID 与已登录会员绑定身份进行核对。
