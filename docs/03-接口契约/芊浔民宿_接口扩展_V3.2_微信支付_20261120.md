# 芊浔民宿接口扩展 V3.2：微信支付

发布日期：2026-11-20（Asia/Shanghai）

## 版本关系

本扩展增补 V3.1 接口，不重定义无关接口。JSON 属性遵循全局 `snake_case` 和统一响应结构。所有会员接口均要求会员 JWT；微信平台通知入口由签名验签保护。

## 支付方式

`POST /api/app/payments/prepay` 的响应新增：

```json
{"payment_method":"MOCK"}
```

`payment_method` 为 `MOCK` 或 `WECHAT`，在创建流水时依据服务端 `WECHAT_PAY_ENABLED` 固化。`WECHAT_PAY_ENABLED=true` 时，`POST /api/app/payments/{payment_no}/mock-pay` 返回冲突，不允许模拟支付。

### 创建微信预支付

`POST /api/app/payments/{payment_no}/wechat-prepay`

请求：

```json
{"login_code":"wx.login 一次性 code","phone_code":"手机号授权一次性 code"}
```

仅微信模式下的本人待支付交易可调用。响应 `data` 返回 `app_id`、`time_stamp`、`nonce_str`、`package`、`sign_type`、`pay_sign`，供 `wx.requestPayment` 使用。服务端校验当前会员手机号并绑定 OpenID；客户端成功回调后仍须查询 `/api/app/payments/{payment_no}` 等待服务端通知结算。

## 微信通知

- `POST /api/payment/wechat/notify/payment`
- `POST /api/payment/wechat/notify/refund`

回调要求 HTTPS、公网可达，保留微信支付请求头及原始请求体供 APIv3 SDK 验签和解密。处理成功返回 HTTP 200；无效签名或不匹配数据返回错误，由微信重试通知。

## 微信退款

原有 `POST /api/app/orders/{id}/refunds` 根据原支付方式分流。模拟支付维持同步模拟结果；微信支付返回 `PENDING`，等待微信退款通知。

新增 `GET /api/app/orders/{id}/refunds/latest`，只返回当前会员本人订单最近退款的 `{refund_id, refund_no, status}`；无退款时 `data` 为 `null`。客户端可轮询该接口，直至 `SUCCESS` 或 `FAILED`。

## 订单详情

`GET /api/app/orders/{id}` 新增 `payment_method`，值为 `MOCK`、`WECHAT`；历史无关联流水时为 `null`。
