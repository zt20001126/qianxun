# 小程序邀请功能接口扩展

本扩展与 V3.1 统一响应、会员认证和分页约定配合使用。第一阶段不涉及订单、奖励或转账。

## 获取或初始化邀请标识

`POST /api/app/invitations/share-code`，需要会员 JWT，无请求体。首次调用持久生成随机邀请标识，后续返回同一标识，标识不设常规过期时间。

```json
{"code":200,"message":"success","data":{"invite_code":"AbCdEf0123456789_-XYZA"}}
```

## 静默尝试绑定

`POST /api/app/invitations/bind`，需要会员 JWT。被邀请人从 JWT 获取，不接收客户端会员 ID。

```json
{"invite_code":"AbCdEf0123456789_-XYZA"}
```

标识为 22 位 URL-safe Base64 字符；格式正确时，无论新建关系、自邀、标识不存在或已有关系，都返回 `{"code":200,"message":"success","data":{}}`，表示请求已处理，不表示必然创建关系。格式错误返回 400，未认证返回 401，服务异常返回 500。被邀请人只能绑定一人；已有关系不自动更换；允许相互邀请。客户端对绑定失败不提示、不阻碍正常使用。

## 查询本人邀请记录

`GET /api/app/invitations?page=1&size=20`，需要会员 JWT；页码从 1 开始，size 默认 20、最大 100。按绑定时间及关系 ID 倒序，total 为本人邀请人数。

```json
{"code":200,"message":"success","data":{"list":[{"masked_phone":"138****1234","bound_at":"2026-11-21T14:30:00+08:00"}],"total":1,"page":1,"size":20}}
```

仅返回当前会员的记录和脱敏手机号；不符合 11 位数字格式的号码返回 `****`。空列表返回 `list: []` 和 `total: 0`。时间按北京时间输出带偏移量的 ISO 8601。
