# 后台基础对话智能体接口补充说明

本补充说明记录经确认新增的后台智能体接口。接口使用后台管理员 JWT，统一响应为 `code/message/data`，字段为 snake_case。管理员只能访问自己的会话。

## POST /api/admin/agent/chat

首次对话请求：`{"message":"你好"}`；继续会话：`{"conversation_id":1,"message":"继续"}`。消息不能为空且不超过 10000 字；会话 ID 须为正整数。首次对话在模型成功后创建会话，以输入前 40 个字符作为标题。

普通回答的 data：`{"conversation_id":1,"status":"completed","answer":"您好"}`。

提问结果的 data 包含 `question_message_id` 和 `questions`。每批 1–3 题，`text` 表示自由文本，`single_choice` 表示四选一，选项包含 `label` 和 `description`，`allow_custom_input` 为 false，`context` 可选。

结构化答题示例：`{"conversation_id":1,"question_message_id":26,"answers":{"purpose":"小红书","audience":"亲子家庭"}}`。本模式不得同时提供 `message`；答案必须覆盖全部问题，自由文本答案最多 100 字，单选答案须与对应选项标签一致。仅当前管理员所属会话的最新助手题卡可以回答；重复提交、题卡过期或并发更新返回 409。答题成功后用户消息的 `content.parts` 包含 `text` 和 `question_answers`，后者保存题卡消息 ID 与答案用于历史恢复。普通聊天的原有请求方式仍然支持。

服务端读取最近 40 条消息；更早消息不传给模型。系统与智能体提示词由服务端注入。模型失败时不保存该轮消息；同一会话并发更新导致上下文变化时返回 HTTP 409，调用方应重新读取消息并重新提交。并发请求可能已产生模型调用费用。第一版不提供自动请求去重。

## GET /api/admin/agent/conversations

`page` 从 1 开始，`size` 默认 20，允许 1–100。data 为 `list/total/page/size`，列表项包括 `id/title/created_at/updated_at`，按更新时间及 ID 降序排列。

## GET /api/admin/agent/conversations/{id}/messages

分页参数同上，消息按 ID 升序排列。列表项包括 `id/role/content/created_at`。content 为 `{"parts":[{"type":"text","text":"..."}]}` 或 `{"parts":[{"type":"questions","questions":[...]}]}`。时间带北京时间偏移。不存在或不属于当前管理员的会话返回 404。

模型服务不可用或模型输出非法时返回 503；其他输入或认证问题沿用项目统一异常处理。接口不提供流式输出或会话删除。

## 运行配置

通过环境变量 `DEEPSEEK_API_KEY` 提供密钥，`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`、`DEEPSEEK_TIMEOUT_SECONDS` 可分别配置服务地址、模型和超时秒数。默认地址为 `https://api.deepseek.com`，默认模型为 `deepseek-flash`，默认超时 60 秒。不要将密钥提交至仓库。服务启动时 Flyway 会执行尚未应用的迁移。
