# 邀请首单奖励接口扩展

`GET /api/app/invitations` 每项增加 `has_completed_order` 布尔值，仅表明是否完成符合奖励规则的房间订单；不返回订单或奖励。原分页、脱敏及权限规则保持。

`GET /api/admin/invitations?page=1&size=20` 仅管理员访问，可选 `phone` 为 1–11 位数字的部分匹配，同时查找邀请人及被邀请人；可选 `reward_status` 为 `ALL`（默认）、`NO_REWARD`、`UNISSUED`、`ISSUED`，筛选在分页前执行，total 为筛选后数量。分页返回 `list/total/page/size`，列表项包含 `id`、`inviter_id`、`inviter_phone`、`invitee_id`、`invitee_phone`、`bound_at`、`order_no`、`paid_amount`、`reward_amount`、`reward_issued`；未产生奖励时订单及金额字段可省略，金额是两位小数字符串。按绑定时间及 ID 倒序。

`PUT /api/admin/invitations/{id}/reward-issued` 仅管理员访问，请求体 `{"reward_issued":true}`，成功返回统一结构的空对象；不存在返回 404，无奖励或尝试设置 `false` 返回 422。重复标记已发放幂等，已发放不能撤销。该操作仅记录发放状态，不执行付款。
