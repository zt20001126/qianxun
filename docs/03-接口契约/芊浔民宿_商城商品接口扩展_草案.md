# 商城商品接口扩展（实现中）

本文件记录当前商城商品、订单查询、支付和退款接口；真实微信渠道及开发者工具完整流程仍待联调，不能视为已完成上线验收。沿用统一响应、snake_case、会员和管理员 JWT 鉴权。价格以两位小数字符串返回。

## 商品对象

`id`、`name`、`description`、`images`（地址数组）、`price`、`status`（`ON_SHELF` 或 `OFF_SHELF`）、`created_at`、`updated_at`。时间为带时区偏移的 ISO 8601 字符串。

## 会员接口

- `GET /api/app/mall/products?page=1&size=20`：分页返回 `list/total/page/size`，仅包含已上架商品。
- `GET /api/app/mall/products/{id}`：查询已上架商品；不存在或已下架时返回 404。

## 管理员接口

- `GET /api/admin/mall/products?page=1&size=20`：分页返回 `list/total/page/size`，包含全部商品。
- `POST /api/admin/mall/products`：接收 `name`、`description`、`images`、`price`，创建下架商品。
- `PUT /api/admin/mall/products/{id}`：接收相同字段，修改商品资料，不修改上架状态。
- `POST /api/admin/mall/products/{id}/status`：接收 `status`（`ON_SHELF` 或 `OFF_SHELF`），调整上架状态。

现阶段后台填写已存在的图片 URL，尚无商城图片上传接口。

## 商城订单及模拟支付（开发中）

新生成的商城订单号采用 `QXYYYYMMDDNNNN`，与住宿订单共用北京时间日流水，四位流水不足时扩展；既有历史订单号不修改。

- `GET /api/app/mall/orders?page=1&size=20`：返回本人商城订单分页；不得跨会员查询。
- `GET /api/app/mall/orders/{id}`：返回本人商城订单详情，包含商品快照、收货信息、金额与积分抵扣、订单状态及物流；非本人或不存在均返回 404。
- `GET /api/admin/mall/orders?page=1&size=20`、`GET /api/admin/mall/orders/{id}`：管理员查询商城订单。
- `POST /api/admin/mall/orders/{id}/ship`：待发货订单提交 `express_company` 和 `tracking_no` 发货；退款处理中不可发货。
- `POST /api/admin/mall/orders/{id}/complete`：已发货订单完成并发放一次积分奖励，重复请求返回已完成订单。
- `POST /api/app/mall/payments`：提交 `product_id`、`quantity`、`points_used`、`recipient_name`、`recipient_phone`、`shipping_address`，返回支付快照和按服务端配置选择的支付方式。
- `GET /api/app/mall/payments/shipping`：返回当前会员付款成功时保存的默认收货资料；首次购买返回空字段。
- `POST /api/app/mall/payments/preview`：提交 `product_id`、`quantity`、`points_used`，返回商品总额、可用积分、最大抵扣积分、抵扣金额与应付金额；提交支付时重新计算。
- `GET /api/app/mall/payments/{payment_no}`：查询本人商城支付状态。
- `POST /api/app/mall/payments/{payment_no}/mock-pay`：模拟环境结算，重复请求返回原订单；开启微信配置时拒绝模拟支付。
- `POST /api/app/mall/payments/{payment_no}/wechat-prepay`：提交 `login_code` 和 `phone_code`，验证会员身份后获取微信支付参数。
- `POST /api/app/mall/orders/{id}/refund`：本人待发货订单按原支付渠道申请整单退款；重复请求复用原退款结果或处理中流水，已发货订单提示联系商家。

微信支付使用现有服务端开关和回调 URL。只有服务端验证微信结果后才创建正式订单；重复通知必须返回同一订单。预支付请求结果不明时保留积分预占并持续对账，不能把客户端回调当作成功凭证。微信退款处理中保持订单待发货且不能发货；退款成功后原子更新订单并返还已抵扣积分。订单完成后按实付金额向下取整奖励会员积分和成长积分，每单最多一次。
