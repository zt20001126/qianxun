# 芊浔民宿商城数据库扩展

商城采用独立表，沿用 MySQL 8、InnoDB、`utf8mb4`，迁移见 `backend/src/main/resources/db/migration/V16__create_mall.sql` 和 `V17__seed_silk_quilt.sql`。已执行的版本化迁移不得修改；后续变更另增版本。

| 表 | 字段与职责 |
| --- | --- |
| `mall_product` | `id/name/description/images/price/status/created_at/updated_at`；商品图片为 OSS 公开 URL JSON 数组，数组顺序即展示顺序，首图为封面。 |
| `mall_order` | `id/order_no/member_id/product_id/product_name/quantity/total_amount/paid_amount/points_used/recipient_name/recipient_phone/shipping_address/status/express_company/tracking_no/paid_at/shipped_at/completed_at/created_at/updated_at`；商品名称及收货资料为支付成功时快照。 |
| `mall_payment` | `id/payment_no/mall_order_id/member_id/product_id/product_name/quantity/total_amount/points_used/amount/recipient_name/recipient_phone/shipping_address/payment_method/transaction_id/wechat_prepay_id/status/expires_at/paid_at/created_at/updated_at`；同时保存待支付快照及支付结果。 |
| `mall_refund` | `id/mall_order_id/mall_payment_id/refund_no/wechat_refund_id/amount/status/refunded_at/created_at/updated_at`；记录商城原渠道退款。 |
| `members` | 新增可空 `default_recipient_name/default_recipient_phone/default_shipping_address`，支付成功后更新。 |
| `points_log` | 新增可空 `mall_order_id` 外键；商城流水采用独立 `ref_no` 命名空间，保持已有住宿流水关联。 |

订单号按 `QXYYYYMMDDNNNN` 与住宿订单共用事务内日流水，保留各表唯一约束；本次实现不修改历史订单号。商品订单为一单一种商品，不增加订单明细表；不增加库存、规格、多地址或独立待支付表。微信预支付请求在途时使用内部标识保留积分预占；渠道状态未确认时不得直接释放。字段精度、索引及检查约束以迁移为准。
