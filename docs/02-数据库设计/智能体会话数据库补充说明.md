# 智能体会话数据库补充说明

经确认新增两张表，具体字段与约束以 Flyway `V21__create_agent_conversation_and_message.sql` 为准。两表使用 MySQL 8、InnoDB、utf8mb4；数据库时间按 Asia/Shanghai 存储。

- `agent_conversation`：管理员、标题与创建/更新时间；按管理员和更新时间索引。
- `agent_message`：会话、角色、JSON 内容与创建时间；按会话和消息 ID 索引。角色仅 `user`、`assistant`。普通文本和自由文本问题保存于 `content.parts`。

外键关联现有 admin 和会话。模型请求不持有数据库锁；保存时锁定会话并检查最新消息，用户消息和助手结果在同一事务写入。当前不存储模型思考内容及工具调用协议，也不持久化失败的对话轮次。
