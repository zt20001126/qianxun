# 芊浔民宿数据库扩展 V3.2：微信支付

发布日期：2026-11-20（Asia/Shanghai）

## 版本关系

本文是在 V3.1 数据库设计上的增量变更。通过 Flyway `V10__wechat_payments.sql` 执行，不修改已应用迁移。V3.1 的其余表结构保持不变。

## `payments` 增量字段

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `payment_method` | `VARCHAR(20) NOT NULL DEFAULT 'MOCK'` | `MOCK` 或 `WECHAT`；检查约束拒绝其他值 |
| `wechat_prepay_id` | `VARCHAR(128) NULL` | 微信 JSAPI 预支付标识；只有微信流水使用 |

增加 `(payment_method, status)` 索引。迁移后既有记录默认归类为 `MOCK`。

## 会员 OpenID

V3.1 `members` 表已含可空、唯一的 `openid` 字段，本扩展不新增 `members` 字段，也不要求批量回填。会员微信授权登录时，核验微信手机号后绑定现有字段；管理员预建会员按手机号复用，不自动换绑。

## 退款

复用现有 `refunds` 表和 `PENDING/SUCCESS/FAILED` 状态。微信受理退款时写 `PENDING`；微信确认成功时写微信退款单号及完成时间。失败流水不修改订单或积分。退款金额继续为整笔原支付金额。
