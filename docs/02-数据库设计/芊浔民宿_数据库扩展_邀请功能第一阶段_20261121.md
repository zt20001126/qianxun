# 邀请功能第一阶段数据库扩展

通过 Flyway `V15__create_member_invitations.sql` 扩展，不修改已应用迁移。该扩展新增一张业务表，属于 V3.1 范围外经用户确认的功能。

`members` 新增 `invite_code VARCHAR(32) CHARACTER SET ascii COLLATE ascii_bin NULL` 与唯一索引；使用时按需生成、长期保留，不要求回填已有会员。随机标识不含手机号，唯一索引负责并发冲突保护。

新增 `member_invitation`：`id` 为主键，`inviter_member_id` 和 `invitee_member_id` 关联 `members.id`，`created_at`、`updated_at` 为北京时间业务时间 `DATETIME(3)`。被邀请人列唯一；检查约束禁止相同会员自邀；邀请人及创建时间组合索引用于查询。允许 A、B 相互邀请，已有关系不会被后续请求更换。

本阶段不改变订单表、不新增返现或转账表。日后奖励与转账数据模型另行设计；第二阶段不补发其上线前订单奖励。
