# 邀请首单奖励数据库扩展

在 `member_invitation` 新增 `reward_order_id`（关联房间订单，唯一、可空）、`reward_amount`（DECIMAL(12,2)，可空）和 `reward_issued`（非空布尔，默认 false）。前两者同时为空或同时非空，金额非负；无奖励时不能标记已发放。每个被邀请人沿用既有唯一约束，无需新增表。旧关系不回填。订单实付关联 `order_amount`，成功支付时间关联 `payments`。退房事务按被邀请人关系行锁串行处理首单并原子写入奖励；管理员手动标记已发放且不能改回未发放，标记不触发转账。

V20 迁移历史记录用于确定首次部署的固定生效边界；`installed_on` 为秒精度，取其北京时间的下一整秒，保守排除边界所在秒。启动时读取并校验该记录，多实例和重启均使用同一值，不新增业务表。
