# 芊浔民宿线上商城需求设计

当前的芊浔民宿小程序已有的功能有线上房间预定、邀请好友（暂未实现邀请返现，只是记录邀请关系）。接下来我还需要实现一个线上商城的功能，需要增加一个除了预定房间以外的线上商城功能，里面可以让用户购买民宿自家商品。新增加的商城功能需要增加哪些数据库表。
商品表：商品id、商品名称、商品描述、商品图片列表、价格、创建时间、更新时间

还需要增加商品订单和商品支付表（我不知道原有的预定房间的订单表是否能够复用），我需要记录订单的id、手机号、收货人、收获  地址、订单创建时间、订单状态、订单创建时间、订单更新时间。

支付表我不知道是否需要能够复用原本的付款记录表。

还需要为member表中增加一个地址字段，这个字段可以为空。如果用户在下单的时候填写了地址信息，那么就保存到这个字段中。如果用户第二次在商城下单填写订单信息的时候默认加载之前保存的地址。订单表是否需要增加快递名称和快递编号。如果订单状态为已发货就需要管理员写入快递信息。
