# 芊浔民宿商城需求扩展

商城独立于客房预订，使用同一会员、积分余额和配置决定的支付渠道；销售收入不计入现有住宿经营报表。邀请功能仍仅记录邀请关系。

## 商品与下单

- 商品由管理员创建、修改、上架和下架；名称、描述、图片列表、价格为商品资料，规格写入描述，不管理库存。
- 一笔订单只购买一种商品，可购买多件；不计算运费。订单金额包含商品总额和实付金额。
- 下单填写收货人、收货手机号及地址。支付成功后才保存为会员默认收货资料；正式订单保存该次收货资料和商品名称快照，不保存商品描述及图片快照。
- 待支付期间商品价格和名称使用交易快照。只有支付成功才创建正式订单。
- 积分兑换比例和最高抵扣 20% 规则沿用住宿业务，计算余额时扣除商城和住宿交易的预占。预支付只预占，成功结算后扣减。

## 状态与退款

- 正常状态为待发货、已发货、已完成；待发货订单整单退款成功后为已退款。
- 管理员发货时填写快递公司和单号，一单一个包裹；管理员完成订单后按实付金额向下取整奖励可用积分和成长积分，每单最多一次。
- 仅待发货订单可自助整单退款，已发货用户联系商家。退款成功返还已抵扣积分。微信退款结果不明或处理中时保留原订单状态并阻止发货。
- 商城新订单号与住宿共用北京时间日流水，格式 `QXYYYYMMDDNNNN`，流水超过四位时扩展。历史订单号不改写。

## 支付与验收边界

系统根据现有支付配置选择模拟支付或微信支付。微信支付与退款均以服务端验证后的渠道结果为准；重复请求或通知不得重复创建订单、扣积分、退款或奖励。渠道状态不明时保留积分预占并对账。真实微信渠道、小程序完整流程及运行环境仍需独立联调验收；本需求文档不代表已部署或已通过真实资金测试。
