# 芊浔民宿需求扩展 V3.3：顾客画像

> 记录用户确认的管理端顾客画像能力，不覆盖 V3.1 中其他业务规则。

## 1. 身份与生命周期

- 预订人手机号（去除首尾空格）是画像唯一标识，同一手机号无论预订人姓名如何变化，都对应一条画像；姓名仅用于显示。
- 手机号为空时，订单可按订单主键保留独立画像，不能与其他订单合并。
- 画像在入住、退房和订单完成后仍可持续编辑。
- 画像字段可以为空；顾客画像不表示手机号已经过本人验证。

## 2. 画像信息

| 信息 | 规则 |
| --- | --- |
| 年龄 | 管理员可手工录入；身份证号可在浏览器内推算年龄，不提交或保存身份证号 |
| 地区 | 管理员可手工编辑；身份证号可在浏览器内推算省级地区，不提交或保存身份证号 |
| 用户群体 | 从固定选项中选择：独自出行、情侣/夫妻、亲子家庭、家庭/亲友、朋友结伴、商务/差旅、团队/团体、其他 |
| 用户标签 | 标签可多选；预置古镇游览、自驾、晚到、亲子设施、长住、复住；管理员可新增全局可复用标签；画像所选标签可持续编辑 |
| 管理员备注 | 每个手机号画像一条长期备注，可持续编辑 |
| 用户下单备注 | 每笔订单的用户备注继续保留在该订单；画像页将同一手机号所有订单备注汇总在同一栏，编辑时按订单逐笔修改，汇总随之更新 |

## 3. 订单统计

- 累计订单数和累计消费金额仅统计 `COMPLETED` 订单；金额使用订单实付金额。
- 已完成订单列表显示订单号、入住日期和实付金额。
- 画像编辑不修改订单状态、金额、积分、日期或库存。

## 4. 管理端录入与编辑

- 管理员可在第三方订单创建和办理入住时补充年龄、地区、群体和标签。
- 管理员可从顾客画像页面持续编辑画像管理员备注及关联订单的用户备注、订单管理员备注；任何订单状态均可编辑。
- 用户群体分类固定定义，标签选项由系统预置并允许管理员新增；新增标签可供所有画像选择。

## 5. 身份证号处理

- 身份证号只存在于画像表单组件的临时内存。
- 浏览器本地推算年龄和省级地区；请求只提交推算结果。
- 身份证号不进入 HTTP 请求、日志、数据库、本地存储或会话存储。
