# 邀请首单奖励需求扩展

在已有邀请关系基础上，仅被邀请人绑定后且功能生效后支付的第一笔完成退房的房间订单产生一次邀请奖励，按实付金额的 10% 四舍五入到分。零元订单奖励为零且占用机会。取消退款订单不占机会；商城订单和历史订单不参与。小程序本人邀请列表仅展示红色“未下单”或绿色“已下单”，以合格订单完成为准，不展示奖励金额。管理员查看关系、订单、实付、奖励及发放状态，可在系统外发放后登记为已发放，已登记发放不能改回未发放。系统不自动发放或转账。本扩展替代邀请第一阶段文档中不计算奖励的限制。

功能首次部署后自动生效，不需要人工设置生效时间；重启不会重置生效时间。

管理员可按邀请人或被邀请人手机号（支持部分号码）及奖励发放状态组合筛选；无奖励、未发放、已发放以颜色和文字区分。
